# 📊 React Estado - Contador Responsivo

Este proyecto es una práctica de **React** para aprender a manejar **estados (useState)** y eventos.  
Consiste en un **contador simple** con dos botones: **Incrementar** y **Decrementar**.  

Además, está diseñado con un estilo **turquesa** y es totalmente **responsivo** (se adapta a móviles y escritorio).

---

## 🚀 Tecnologías utilizadas
- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- CSS (custom)
